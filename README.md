# Security Architecture Labs

A collection of security architecture exercises, reference designs, implementation plans, and technical labs focused on enterprise security engineering.

## Focus Areas

- Email security architecture
- Cloud security guardrails
- Identity security
- Secure enterprise AI
- Retrieval-augmented generation security
- AI agent security
- Security architecture patterns

## Purpose

These projects demonstrate how I approach security problems from architecture through implementation, including:

- Current-state assessment
- Threat and risk analysis
- Architecture design
- Control selection
- Migration planning
- Validation and testing
- Operational considerations
- Tradeoff analysis

All examples are generalized and contain no confidential employer information.
